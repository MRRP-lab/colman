# Questionare

At the start:
- I would feel uneasy if I had a job where I had to use robots.


Questions, after each video:
- Who's to blame?
- Could the human have avoided it?
- Could the robot have avoided it?
- Was the robot arm making it's own decision, or following a program?
- Did the robot pickup the red or blue cube? (data attention)

At the end:
- Rank which robot you'd want to work with.
- Overall, when something went wrong, whose fault was it usually?
